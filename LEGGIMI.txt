NH90 Performance - app installabile (PWA)

Contenuto: index.html, manifest.webmanifest, sw.js, cartella icons.
Mantieni questa struttura: i file vanno pubblicati insieme, nella stessa cartella.

1. Pubblicazione (serve un indirizzo https)
   Esempio con GitHub Pages: crea un repository, carica tutti i file,
   poi Settings > Pages > Deploy from a branch > main / (root).
   Dopo un minuto l'app risponde su https://<utente>.github.io/<repository>/

2. Installazione
   iPhone / iPad: apri l'indirizzo in Safari > Condividi > Aggiungi alla schermata Home.
   Android: apri l'indirizzo in Chrome > menu > Installa app.

3. Offline
   Dopo la prima apertura l'app funziona anche senza rete.

4. Aggiornamenti
   Sostituisci i file sul sito e attendi che GitHub Pages finisca la pubblicazione
   (scheda Actions, spunta verde; poi fino a 10 minuti di cache di GitHub).
   Con rete l'app carica sempre l'ultima versione all'apertura; se era già aperta
   compare la barra "Nuova versione disponibile" con il pulsante Aggiorna.
   La versione in uso è scritta nella Home (es. v33) e in sw.js.

5. Performance Data
   I dati inseriti restano salvati sul telefono (solo in quel browser).
   OAT di atterraggio e crociera: stimate dall'OAT di decollo con la stessa
   deviazione ISA. Quote convertite in pressure altitude con il BARO.

Nota: un sito GitHub Pages è pubblico. Verifica che i dati ricavati dal manuale
si possano pubblicare; in alternativa usa un hosting con accesso protetto.
Strumento di supporto: per l'impiego in volo fa fede il manuale ufficiale.
